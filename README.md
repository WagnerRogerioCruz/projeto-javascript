\# Cadastro de Estudantes - v1.0



Aplicação web desenvolvida em JavaScript para gerenciamento de estudantes, cálculo de desempenho acadêmico e sistema de gamificação.



\## Funcionalidades



\### Gestão de Estudantes



\* Cadastro de estudantes

\* Cadastro de responsável

\* Cadastro de telefone e e-mail

\* Busca de estudantes por nome

\* Persistência dos dados utilizando LocalStorage



\### Avaliação Acadêmica



\* Cálculo de média ponderada

\* Cálculo automático de frequência

\* Classificação por conceito (A, B, C, D e E)

\* Determinação automática de:



&#x20; \* Aprovado

&#x20; \* Em Recuperação

&#x20; \* Reprovado por Nota

&#x20; \* Reprovado por Frequência

&#x20; \* Reprovado por Frequência e Nota



\### Interface



\* Modo Professor

\* Modo Aluno

\* Alternância dinâmica entre modos

\* Layout responsivo utilizando CSS Grid e Flexbox

\* Feedback visual através de popups



\### Gamificação



\* Seleção de aluno para desafios

\* Jogo de adivinhação

\* Sistema de bônus por desempenho

\* Bônus acumulado diretamente na média do aluno

\* Controle de limite máximo de média (10,0)



\### Validações



\* Validação de campos obrigatórios

\* Validação de notas

\* Validação de frequência

\* Tratamento de erros com try/catch

\* Proteção contra entradas inválidas



\## Tecnologias Utilizadas



\* HTML5

\* CSS3

\* JavaScript (ES6+)

\* LocalStorage
